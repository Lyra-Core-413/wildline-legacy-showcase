## What the private rework implements

- Open constellation clusters at varying distances and depths, progressive detail, restrained source connections and Off / Focus / Tour label modes.
- Local search and source inspection, source-attributed Threads, a chronological Timeline and a read-only Command Center that flags explicit task conflicts without rewriting source status.
- Reversible owner-reviewed identity mappings. Matching names are review candidates, not automatic person merges.
- Optional owner-authored reflections and Legacy chapter drafts with separate authorship.
- A retained JSON archive and nonconflicting owner-overlay restore preview. This supports portability; it is not complete database disaster recovery or a replacement for provider backups.

Permitted local polling and owner-only phone access operate in the owner's environment. They are separate from the bounded Bee Bridge demonstration and from both public static views. No public Bee service, family multi-user access or arbitrary-device compatibility is established by this work. ## Verification and its limits

The retained private audit reports 465 passing JavaScript tests and eight passing information-audit fixtures. A 30-minute-31-second actual-browser functional session exercised the rotating map and automatic topic traversal without reported console errors. These checks belong to the private implementation and are not reproducible from this static repository or additive to the public Bridge, Reader or Reading Room test counts.

The embedded preview throttled long-running frame scheduling. The session establishes finite functional coverage, not a sustained frame-rate guarantee, production readiness or absence of every memory leak. Large synthetic metadata indexing fixtures do not demonstrate a million-record renderer or production database. Same-name identities, conflicting task evidence and potentially sensitive material still require owner review; an audit is not independent verification of every life claim.

Live embedded voice, microphone use and automatic map-context transfer are not enabled by this rework. The public LYRA launcher opens ChatGPT separately; Voice starts manually. Family access and a paged lifetime-data pipeline remain future work.
